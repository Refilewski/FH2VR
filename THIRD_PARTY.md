# Third-party components

## FH2ML SDK header

`include/FH2ML.h` is copied from the FH2ML SDK header and is distributed upstream under the MIT license for the SDK headers.

## OpenVR

FH2VR builds against Valve's OpenVR SDK v2.15.6. CMake fetches the SDK source at configure time; OpenVR source and binaries are not committed to this repository.

OpenVR is distributed by Valve under the BSD 3-Clause license. See the upstream ValveSoftware/openvr repository for the complete license text.
